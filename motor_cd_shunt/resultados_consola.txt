A.1) Punto de operacion inicial (n1 = 1600 rpm, w1 = 167.5516 rad/s)
   If  = Va/Rf          = 120/120           = 1.0000 A
   Ia  = IL - If        = 20 - 1.0        = 19.0000 A
   Ea  = Va - Ia*Ra     = 120 - 19.0*0.5   = 110.5000 V
   Ke  = Ea/w1          = 110.5/167.5516   = 0.659498 V.s/rad
   Kt  = Ke (SI)                          = 0.659498 N.m/A
   Tm  = Kt*Ia                            = 12.5305 N.m
   Pconv = Ea*Ia = 2099.50 W  ;  Tm*w1 = 2099.50 W  (deben coincidir)
   Ke por amperio de campo: kf = Ke/If    = 0.659498 V.s/(rad.A)
   Observacion: B*w1 = 12.5664 N.m ~ Tm = 12.5305 N.m  -> con TL = 0 la
   friccion viscosa B ES la carga del punto inicial (ver guia).

A.2) Nueva Rf para n2 = 1800 rpm (w2 = 188.4956 rad/s) a par constante T = 12.5305 N.m

   Discriminante = 9676.1250

      Ea casi nula y un flujo de apenas 8.7% del inicial: punto inestable/irreal.
   Ke2 = Kt2 = 0.579237   (phi2/phi1 = 0.87830)
   Ia2 = T/Ke2 = 21.6327 A ;  Ea2 = Va - Ia2*Ra = 109.1836 V  (check Ke2*w2 = 109.1836 V)
   If2 = If1*(Ke2/Ke1) = 0.87830 A
   Rf' = Va/If2 = 136.6276 Ohm   (aumento de 16.63 Ohm)
   IL2 = Ia2 + If2 = 22.5110 A ;  Pconv2 = Ea2*Ia2 = 2361.94 W = T*w2 = 2361.94 W
   Aproximacion rapida (Ea ~ cte):  Rf' ~ Rf*n2/n1 = 135.00 Ohm  (error 1.19%)
